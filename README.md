# Tycoon — тайкун для Roblox Studio

Готовая игра-тайкун: шесть заводов, дропперы, конвейер, улучшители, покупки за игровые деньги, перерождения и сохранение прогресса. Весь мир и все скрипты лежат в одном файле `Tycoon.rbxl`.

## Как открыть

1. Скачай файл `Tycoon.rbxl`.
2. Открой его в Roblox Studio: двойной клик по файлу или **File → Open from File**.
3. Нажми **Play** (F5).

## Как играть

1. Подойди к свободному заводу и встань на зелёную площадку у ворот — завод станет твоим.
2. Наступай на круглые кнопки на полу, чтобы покупать предметы. Зелёная кнопка — денег хватает, красная — пока нет. Первый дроппер бесплатный.
3. Дропперы роняют руду на конвейер, улучшители умножают её цену, печь в конце ленты превращает руду в деньги.
4. Заработанное копится в банке завода. Встань на жёлтую площадку у печи, чтобы забрать деньги.
5. Купив всё, наступи на кнопку «Перерождение»: завод начнётся заново, а доход навсегда вырастет на 50%.

## Как менять игру

Почти всё настраивается в Studio без правки кода — через атрибуты в окне **Properties**. Заводы лежат в `Workspace.Tycoons`, у каждого одинаковое устройство:

| Объект | Атрибут | Что делает |
| --- | --- | --- |
| `Buttons/Buy…` | `Price` | Цена покупки |
| `Buttons/Buy…` | `Label` | Название на кнопке |
| `Buttons/Buy…` | `Requires` | После покупки какого предмета кнопка появляется |
| `Buttons/Buy…` | `Item` | Какую модель из `Items` продаёт кнопка |
| `Items/Dropper…` | `OreValue` | Цена одной руды |
| `Items/Dropper…` | `DropInterval` | Пауза между рудой в секундах |
| `Items/Dropper…` | `OreColor`, `OreMaterial`, `OreSize` | Вид руды |
| `Items/Upgrader…` | `Multiplier` | Во сколько раз улучшитель умножает цену руды |

Заводов шесть, и атрибуты у каждого свои: меняй нужный атрибут на всех заводах.

Общие настройки (скорость ленты, бонус перерождения, стартовые деньги, все тексты) — в скрипте `ReplicatedStorage.Shared.Config`.

Чтобы добавить свой предмет, положи модель в `Items` и создай для неё кнопку в `Buttons` с атрибутами `Item`, `Price`, `Label` и `Requires`. Дроппером модель делает атрибут `OreValue` и деталь `Spout`, улучшителем — атрибут `Multiplier` и деталь `Beam`.

## Сохранение прогресса

Деньги, перерождения и покупки сохраняются в DataStore. В файле, открытом с диска, DataStore недоступен, поэтому игра работает без сохранения. Чтобы оно заработало:

1. Опубликуй игру: **File → Publish to Roblox**.
2. Включи **Game Settings → Security → Enable Studio Access to API Services**.

Заводов шесть, поэтому после публикации ограничь сервер шестью игроками: параметр **Maximum Visitor Count** в настройках места на Creator Dashboard.

## Для разработчиков

Файл `Tycoon.rbxl` собирается из исходников в этом репозитории:

```
src/shared/   Config и Format — общие модули (ReplicatedStorage.Shared)
src/server/   серверная логика (ServerScriptService.TycoonServer)
src/client/   интерфейс игрока (StarterPlayerScripts.TycoonHud)
lune/map.luau    генератор карты: лобби и шесть заводов
lune/build.luau  сборка place-файла
lune/test.luau   тест логики игры
```

Нужен [Lune](https://lune-org.github.io/docs) 0.11 (версии закреплены в `rokit.toml`):

```sh
lune run build   # собрать Tycoon.rbxl и sourcemap.json
lune run test    # прогнать тест на собранном файле
```

Тест запускает скрипты из собранного файла в Lune с заглушками движка Roblox и проверяет захват завода, покупки, улучшители, перерождение, сохранение и интерфейс, а также геометрию конвейера. Физику и отрисовку он не проверяет — для этого нужен запуск в Studio.

Сборка перезаписывает `Tycoon.rbxl`. Если меняешь карту прямо в Studio, сохраняй файл под другим именем либо не запускай сборку.
